# RDR2 HD map

Source: https://www.gtabase.com/images/red-dead-redemption-2/locations/Red-Dead-Redemption-2-Full-World-Map.jpg
Source page and attribution: https://www.gtabase.com/red-dead-redemption-2/map-locations/
Map: Rockstar Games; stitched image: GTA Base. Their image and watermarks are preserved unchanged; visible attribution is included below the map.
Downloaded 2026-11-09. Native dimensions: 7200 × 5400.

The legacy map is 4320 × 3444 and includes Mexico. Its coordinate space remains canonical for every stored marker; no database migration or rewriting of locations is performed. The high-resolution image is used by default, and the legacy image remains selectable for Mexico.

Registration maps HD pixels to legacy pixels, using 779 matching SIFT landmarks and RANSAC; median residual 0.754 legacy pixels. Matrix in map-alignment.json. Both regular marker edits and craft marker rendering use the forward/inverse conversion.
